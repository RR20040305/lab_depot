# lab_depot — сервис учёта лабораторного оборудования

## Назначение

Приложение для учёта оборудования в лабораториях: хранение информации о каждом
устройстве, отслеживание его состояния, сроков выдачи и ответственных сотрудников.
Помогает избежать потерь, упрощает поиск и контроль за техническим обслуживанием.

Проект развивался по этапам:

- **ПР1–ПР2** — консольное приложение на функциях и словарях;
- **ПР3** — перевод на объектную модель (`Equipment`, `Employee`, `Laboratory`, `Issue`);
- **ПР5** — добавление веб-интерфейса на Django;
- **ПР6** — перевод веб-интерфейса на Django-шаблоны и статические файлы.

После ПР6 у проекта две рабочие версии — консольная (`main.py`) и веб-версия
(`manage.py`). Обе используют общую объектную модель и одни и те же JSON-файлы.

## Используемые технологии

- Python 3
- Django 5.2 — веб-фреймворк
- Django Template Language — шаблоны
- HTML, CSS, Bootstrap 5.3 — разметка и оформление
- JavaScript — небольшая клиентская логика
- pytest — автоматизированные тесты
- flake8 — проверка качества кода

## Целевая аудитория

Сотрудники лабораторий (научные работники, инженеры), заведующие лабораториями,
администраторы, отвечающие за материально-техническую базу.

## Предметная область

Учёт оборудования в научных или производственных лабораториях. Включает
инвентаризацию, перемещение оборудования между лабораториями, выдачу во временное
пользование, фиксацию ремонтов и списаний.

## Основные сущности

### Equipment — оборудование

- Атрибуты: `inv_num` (инвентарный номер), `name` (название), `status`
  (`исправно` / `в ремонте`).
- Методы: `is_available()`, `matches()`, `__str__()`.

### Employee — сотрудник

- Атрибуты: `emp_id` (табельный номер), `fio`, `position`, `lab`.
- Методы: `matches()`, `__str__()`.

### Laboratory — лаборатория

- Атрибуты: `lab_id`, `responsible`, `location`.
- Методы: `matches()`, `__str__()`.

### Issue — выдача оборудования

- Атрибуты: `id`, `equipment` (объект `Equipment`), `employee` (объект `Employee`),
  `return_date`, `status` (`активна` / `завершена`).
- Методы: `cancel()`, `is_active()`, `__str__()`.
- **Взаимодействие объектов**: `Issue` связан с `Equipment` и `Employee`
  через ссылки. В JSON сохраняются только идентификаторы (`inv_num`, ФИО),
  при загрузке выполняется поиск соответствующих объектов.

## Django Template Language

Веб-интерфейс проекта построен на Django-шаблонах. HTML-разметка не формируется
в Python-коде view-функций.

### Базовый шаблон

Общий каркас страниц: `templates/base.html`. Содержит:

- подключение Bootstrap 5.3 через CDN и собственного CSS через `{% static %}`;
- логотип проекта;
- навигацию через `{% include "includes/navigation.html" %}`;
- блоки `{% block title %}` и `{% block content %}` для дочерних страниц;
- подключение JavaScript перед закрывающим `</body>`.
