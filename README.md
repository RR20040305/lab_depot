# Название проекта: Сервис учета лабораторного оборудования 

## Назначение 
Веб-приложение для учёта оборудования в лабораториях: хранение информации о каждом устройстве, отслеживание его текущего состояния, время выдачи и ФИО сотрудников. Помогает избежать потерь, упрощает поиск и контроль за техническим обслуживанием.

## Целевая аудитория
Сотрудники лабораторий (научные работники, инженеры), заведующие лабораториями, администраторы, отвечающие за материально-техническую базу.

## Предметная область
Учёт оборудования в научных или производственных лабораториях. Включает инвентаризацию, перемещение оборудования между лабораториями, выдачу во временное пользование, фиксацию ремонтов и списаний.

## Основные сущности 
- Оборудование – инвентарный номер, название, состояние (исправно / в ремонте).
- Сотрудник – ФИО.
- Выдача – запись о передаче оборудования сотруднику: инвентарный номер, ФИО сотрудника, планируемая дата возврата, статус (активна / завершена).

## Реализованные функции
- **Добавление оборудования** — регистрация новой единицы техники с указанием инвентарного номера, названия и состояния.
- **Редактирование** — изменение названия или состояния существующей записи.
- **Удаление** — удаление записи с проверкой отсутствия активных выдач.
- **Проверка доступности** — определение, можно ли выдать оборудование (учитывается состояние и наличие активной брони).
- **Выдача оборудования** — оформление брони с указанием сотрудника и даты возврата.
- **Отмена выдачи** — завершение активной брони.
- **Поиск** — поиск оборудования по части названия.
- **Сортировка** — сортировка списка по номеру или названию.
- **Статистика** — вывод общего количества оборудования, числа единиц в ремонте и активных выдач.
- **Сохранение данных** — все изменения автоматически сохраняются в файл `data.json`.
