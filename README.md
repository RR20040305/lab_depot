# Название проекта: Сервис учета лабораторного оборудования 

## Назначение 
Веб-приложение для учёта оборудования в лабораториях: хранение информации о каждом устройстве, отслеживание его текущего состояния, время выдачи и ФИО сотрудников. Помогает избежать потерь, упрощает поиск и контроль за техническим обслуживанием.

## Целевая аудитория
Сотрудники лабораторий (научные работники, инженеры), заведующие лабораториями, администраторы, отвечающие за материально-техническую базу.

## Предметная область Краткое описание предметной области.
Учёт оборудования в научных или производственных лабораториях. Включает инвентаризацию, перемещение оборудования между лабораториями, выдачу во временное пользование, фиксацию ремонтов и списаний.

## Основные сущности 
- Оборудование – инвентарный номер, название, модель, серийный номер, состояние (работает/не работает/в ремонте).
- Лаборатория – номер, ответственное лицо, местоположение.
- Сотрудник – ФИО, должность, контакты, лаборатория прикрепления.
- Выдача – запись о передаче оборудования сотруднику: дата выдачи, планируемая дата возврата, фактическая дата возврата, ответственный.

## Основные функции 
- Добавление записи
- Редактирование записи
- Удаление записей об оборудовании
- Проверка возможности выдачи

## План развития 
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
